# Gorilla Guard downloads

Official compiled Gorilla Guard releases for Windows x64. This repository contains release downloads and instructions only. Development source and signing keys are maintained privately.

Download [GorillaGuard.Bootstrap.exe](https://github.com/DevyDevelopment/GorillaGuard-Releases/releases/latest/download/GorillaGuard.Bootstrap.exe), close Gorilla Tag, and run the installer. A complete signed ZIP is also available on the [latest release page](https://github.com/DevyDevelopment/GorillaGuard-Releases/releases/latest).

The installer verifies the update descriptor signature, complete package hash, and internal signed manifest. This is application-level RSA verification, not Windows Authenticode certification. Protection runs in user mode and cannot prove that a PC is cheat-free. See each release for validation results and known limitations.
